## DSP Lab

A hands-on collection of digital signal processing experiments focused on biomedical and sensor data.

## Experiments

### 01 — DSP Fundamentals

Core signal-processing concepts including sampling, FFT/frequency analysis, convolution, FIR/IIR filters, filter design, phase/group delay, notch filtering, and physiological signal filtering.

### 02 — CGM Algorithm Pipeline

An end-to-end simulated continuous glucose monitoring pipeline exploring sensor dynamics, noise, drift, filtering, calibration, and algorithm validation.

## Tools

* Python
* NumPy
* SciPy
* pandas
* Matplotlib
* scikit-learn
* Jupyter
* pytest

Each experiment is organized as a self-contained project with its own notebooks, source code, data, figures, and documentation.
